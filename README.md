# 🍽️ CRAVORA – Delicious Food, Happy Moments

**Cravora** is a modern restaurant website designed to provide an attractive and user-friendly online food browsing experience.

## 🌿 About the Project

Cravora is a frontend web development project built with HTML, CSS and JavaScript. It focuses on modern design, attractive food presentation, interactive elements and responsive layouts.

## ✨ Features

- Modern restaurant homepage
- Attractive hero section
- Popular dishes showcase
- Food photography and video section
- Customer testimonials
- App download promotion
- Interactive navigation
- Shopping cart interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 🎨 Brand Colours

- Mint Green: `#E8F5E9`
- Forest Green: `#1B5E20`

## 📁 Project Structure

- `index.html` – Homepage
- `index.css` – Homepage styling
- `script.js` – JavaScript functionality
- `images/` – Website images and assets

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the Cravora website.
